# 🎵 SoundCloudDownloader

Консольный инструмент для скачивания треков и плейлистов со SoundCloud в максимальном качестве (`MP3 320kbps` + теги и обложки альбомов).

Главная особенность — **встроенный обход блокировок**. Все необходимые утилиты (`FFmpeg` и `wireproxy`) уже зашиты внутрь программы, а для работы VPN используется файл конфигурации, который лежит в папке с приложением.

---

## 📥 Как пользоваться

1. Скачайте архив с последней версией программы из раздела **[Releases](../../releases)**.
2. Распакуйте его в удобную папку. Внутри уже будут находиться сам `.exe` и готовый файл конфигурации `config.conf`.
3. Запустите `SoundCloudDownloader.exe`, вставьте ссылку на трек или плейлист со SoundCloud и заберите готовый MP3-файл с обложкой.
4. После загрузки файл появится рядом с `.exe`.

*(Вы можете в любой момент заменить стандартный `config.conf` на свой собственный файл WireGuard / AmneziaWG, если это необходимо).*

### 📝 Используемые компоненты
* [FFmpeg](https://ffmpeg.org/) — используется для конвертации аудио и работы с тегами (распространяется под лицензиями LGPL/GPL).
* [wireproxy](https://github.com/bropines/awg-wireproxy) — сетевой прокси-клиент для туннелирования трафика.
